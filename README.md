# Progress Tracker: Solo Leveling Edition

A Python app that tracks my progress in golf, climbing, volleyball,
and strength training in a "level up" style inspired by Solo Leveling,
with AI-generated progress summaries.

## Status
In development.

## Setup
1. Clone the repo
2. Create a virtual environment and activate it
3. Run `pip install -r requirements.txt`
4. Run `python main.py`

## Planned features
- Activity logging (gym, golf, climbing, volleyball)
- Progress stats and charts
- Level and XP system based on personal records and goals
- AI coach summaries (Claude API)
